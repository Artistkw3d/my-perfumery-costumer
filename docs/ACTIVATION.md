# دليل التفعيل

التفعيل يتم **مرة واحدة لكل جهاز** ولا يحتاج إنترنت. الخطوات:

## 1) شغّل البرنامج

عند أول تشغيل تظهر شاشة التفعيل، وتعرض **معرّف الجهاز** (Device ID) الخاص بجهازك.

## 2) أدخل الرقم التسلسلي

اكتب الرقم التسلسلي الذي استلمته عند الشراء، بالشكل:

```
MYPF-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX
```

الأحرف الكبيرة والصغيرة والمسافات لا تهم. اضغط **متابعة**.

## 3) أرسل طلب التفعيل

تظهر لك سلسلة نصية طويلة اسمها **"طلب التفعيل"**. انسخها كاملة وأرسلها للبائع
(واتساب / إيميل). هذه السلسلة تحتوي على رقمك التسلسلي + معرّف جهازك فقط، ولا
تحتوي أي بيانات شخصية.

## 4) استلم ملف التفعيل

يرسل لك البائع ملف `activation.cert` (أو نصّه). عندك طريقتان:

- **الصق النص** في الحقل السفلي بشاشة التفعيل واضغط **حفظ وتفعيل**، أو
- **ضع الملف** `activation.cert` في نفس مجلد `MyPerfumery.exe`.

## 5) أعد التشغيل

أغلق البرنامج وافتحه من جديد. سيبدأ مباشرة بدون شاشة التفعيل.

---

## أسئلة شائعة

**نقلت البرنامج لجهاز ثاني ولم يعمل.**
التفعيل مرتبط بجهاز واحد. لكل جهاز إضافي يلزم رقم تسلسلي يسمح بعدد أجهزة أكبر،
أو ملف تفعيل جديد للجهاز الجديد — راجع البائع.

**أعدت تثبيت ويندوز / غيّرت القرص الصلب.**
معرّف الجهاز يتغير في هذه الحالة. راسل البائع بمعرّف الجهاز الجديد للحصول على
ملف تفعيل جديد لنفس رقمك التسلسلي.

**فقدت ملف `activation.cert`.**
راسل البائع بنفس طلب التفعيل؛ سيعيد إرسال نفس الملف.

**ظهرت رسالة "رقم تسلسلي غير صحيح".**
تأكد من نسخ الرقم كاملاً بدون حروف ناقصة. الأصفار والأحرف قد تختلط — انسخه
ولا تكتبه يدويًا إن أمكن.
