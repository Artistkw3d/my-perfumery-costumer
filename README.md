# My Perfumery

تطبيق مكتبي لإدارة تركيبات العطور والمواد الخام وتوافق IFRA وتقارير السلامة (MSDS)
ودفتر ملاحظات العطّار مع الملفات الشمّية.

يعمل بالكامل بدون إنترنت بعد التفعيل. واجهة عربية (RTL).

---

## التنزيل

نزّل أحدث إصدار من صفحة **[Releases](../../releases/latest)**:

| الملف | النظام |
|---|---|
| `MyPerfumery.exe` | ويندوز 10 / 11 (64‑بت) |
| `MyPerfumery.apk` | أندرويد 8 فأحدث *(قريبًا)* |

الملف مستقل ولا يحتاج تثبيت. شغّله مباشرة.

---

## التفعيل

عند أول تشغيل تظهر شاشة التفعيل:

1. أدخل **الرقم التسلسلي** الذي استلمته عند الشراء.
2. تظهر لك رسالة **"طلب التفعيل"** — انسخها وأرسلها للبائع.
3. تستلم ملف `activation.cert` — الصقه في نفس الشاشة (أو ضعه بجانب البرنامج) وأعد التشغيل.

التفعيل مرة واحدة لكل جهاز ويبقى يعمل بدون إنترنت. راجع
[`docs/ACTIVATION.md`](docs/ACTIVATION.md) للتفاصيل.

---

## المتطلبات

- **ويندوز:** 10 أو 11، معمارية 64‑بت، و WebView2 (مثبّت مسبقًا على ويندوز 11
  وأغلب أنظمة ويندوز 10 المحدّثة).
- **أندرويد:** الإصدار 8.0 فأحدث.

## My Perfumery (English)

Desktop application for managing perfume formulations, raw materials, IFRA
compliance, MSDS safety reports, and a perfumer's notebook with olfactive
profiles. Runs fully offline after activation. Arabic (RTL) interface.

**Download:** get the latest build from **[Releases](../../releases/latest)**
(`MyPerfumery.exe` for Windows 10/11 64‑bit; Android APK coming later).

**Activation:** on first launch, enter your serial number → send the shown
activation request to the vendor → paste back the `activation.cert` you
receive → restart. One‑time per device, works offline afterward. See
[`docs/ACTIVATION.md`](docs/ACTIVATION.md).

**Support:** open an [issue](../../issues/new/choose).
